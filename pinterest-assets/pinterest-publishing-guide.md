## How to post each Pin

1. Click `Create` in Pinterest.
2. Upload the SVG file from the `pinterest-assets` folder.
3. Paste the matching pin title.
4. Paste the matching pin description.
5. Paste the matching destination link.
6. Save it to the matching board.
